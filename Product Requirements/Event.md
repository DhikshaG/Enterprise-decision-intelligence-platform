# Events — Investigation Workspace

> **A focused workspace to identify, filter, and investigate operational events.**

## Purpose

Enable users to **find relevant events, understand what happened, and determine where deeper investigation is required.**

![Enterprise Decision Intelligence](./Events.png)

## Core Experience

**Find → Filter → Understand → Investigate**

## Information Hierarchy

| Layer | User Need | Product Response |
|---|---|---|
| **Event Population** | What happened? | Complete event register |
| **Filters** | What am I looking for? | Date, impact, area, type, status, owner, equipment |
| **Event Context** | What does this event mean? | Impact, status, ownership and event details |
| **Investigation** | Why did it happen? | Root cause, impact, history and related events |
| **Action** | What happens next? | Linked actions and decision context |

## Filter Logic

**Select Filter → Context Applied → Relevant Events → Investigate Event**

Filters remain visible and cumulative, ensuring the user understands **why an event appears in the current view**.

## Design Principle

> **Home presents the signal. Events presents the evidence.**

Events is designed for **investigation, not executive reporting**; detailed analytics and cross-event patterns remain within Insights.
